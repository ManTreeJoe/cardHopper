# homebrew-cardhopper

Homebrew tap for [Card Hopper](https://github.com/ManTreeJoe/cardHopper).

## Install

```sh
brew tap ManTreeJoe/cardhopper https://github.com/ManTreeJoe/homebrew-cardhopper
brew install --cask card-hopper
```

## Update

```sh
brew upgrade --cask card-hopper
```

## Uninstall

```sh
brew uninstall --cask card-hopper
```
